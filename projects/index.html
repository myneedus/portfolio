Grocery Processing Cost Comparison

Takeaway: Minimally processed foods cost 1.4–2.1× more per calorie than ultra-processed foods, and the premium changes by store: Target shows the biggest gap, Whole Foods the smallest, and Walmart sits in between.

This chart compares median price per 100 calories across NOVA processing classes for Walmart, Target, and Whole Foods. I converted the raw “price percal” field into a more interpretable unit, $ per 100 calories, by multiplying by 100. The data were cleaned by dropping rows with missing, non-finite, or non-positive values; all remaining store-class cells had at least 30 products, so there was no need for additional sparsity filtering. The key statistical comparison is between class 0 (unprocessed/minimally processed) and class 3 (ultra-processed), since those are the clearest opposing ends of the processing spectrum.

The headline result is that the price premium is real and it varies by store. Target has the largest premium, at about 2.1×, while Walmart is about 1.7× and Whole Foods about 1.4×. One especially useful comparison is that Walmart’s minimally processed foods cost roughly the same per calorie as Target’s ultra-processed foods, which suggests that grocery choice matters almost as much as processing level when shopping for cheaper calories.

I intentionally emphasized the class 0 and class 3 endpoints rather than pretending the middle classes form a smooth monotonic trend. The middle categories are non-monotonic, so this graphic is designed to make the endpoint comparison clear without overstating the pattern. The linear axis also keeps the scale honest: the raw values are about $0.003–$0.012 per calorie, which correspond to roughly $0.30–$1.20 per 100 calories.
